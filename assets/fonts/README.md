# Yerel yazı tipleri

DM Sans ve Manrope, Google Fonts kaynağından alınmıştır. Latin ve Latin Extended alt kümeleri Türkçe karakterleri kapsar. Değişken fontlar yerel sunulur; `fonts.css` içinde tanımlıdır. SIL Open Font License metinleri bu klasördedir.

Kaynaklar: https://fonts.google.com/specimen/DM+Sans ve https://fonts.google.com/specimen/Manrope
